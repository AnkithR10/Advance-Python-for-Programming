## How to Use This Repository

### Run Python files

From the repository root, run a program with:

```bash
python "Lab/Lab 2/Pyramid.py"
```

Replace the path with the Python file you want to execute. Quoting paths is recommended because some folders and filenames contain spaces or special characters.

### Run Jupyter notebooks

1. Install Python 3.10 or newer.
2. Install Jupyter:

	```bash
	python -m pip install notebook
	```

3. Start Jupyter from the repository root:

	```bash
	jupyter notebook
	```

4. Open a notebook from `Assignments/`, `Class/`, or `Lab/` and run its cells in order.

VS Code users can also open any `.ipynb` file directly after installing the **Jupyter** extension and selecting a Python interpreter.

## Learning Focus

The programs in this repository provide practice with:

- Python syntax, input, output, and expressions
- Conditional statements and loops
- `break` and `continue`
- Nested loops, patterns, tables, and matrices
- Functions and lambda expressions
- Basic problem solving through real-world scenarios
- Working with and documenting Jupyter notebooks

## Suggested Study Order

1. Review the notebooks in `Class/` alongside the corresponding examples.
2. Complete the programs in `Lab/Lab 2/` to strengthen control-flow fundamentals.
3. Continue with `Lab/Lab 3/` for functions, lambda expressions, and scenario-based problems.
4. Finish the notebooks in `Assignments/` as revision and assessment work.
