## 🚀 Get started

### Run a Python program

Install Python 3, then run a script from the repository root. Quote paths that contain spaces:

```bash
python "Lab/Lab 2/Pyramid.py"
```

Choose another `.py` file to run a different exercise. Some programs ask for input in the terminal.

### Open a notebook

Install Jupyter if it is not already available:

```bash
python -m pip install notebook
```

Start Jupyter from the repository root:

```bash
jupyter notebook
```

Open any `.ipynb` file under `Class/`, `Lab/`, or `Assignments/`. You can also open notebooks in VS Code with its Jupyter extension.

## 🗺️ Suggested learning path

3. Apply them independently in `Assignments/`.
